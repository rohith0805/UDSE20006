# Personal Portfolio Website

A responsive personal portfolio website created using HTML, CSS, and JavaScript.

## Features

- Responsive design
- Home section
- About section
- Skills section
- Projects section
- Education section
- Contact section
- Download/View Resume
- GitHub, LinkedIn and LeetCode links
- Mobile navigation menu
- Contact form validation
- Automatic copyright year
- Smooth scrolling

## Project Structure

portfolio-website/
│
├── index.html
├── style.css
├── script.js
│
├── images/
│   └── profile.jpg
│
├── assets/
│   └── resume.pdf
│
└── README.md

## Technologies Used

- HTML5
- CSS3
- JavaScript

## How to Run

1. Download or clone the project.
2. Open the project folder in VS Code.
3. Make sure `profile.jpg` is inside the `images` folder.
4. Make sure `resume.pdf` is inside the `assets` folder.
5. Open `index.html` in a browser.

You can also use the VS Code Live Server extension.

## Customization

Replace the following information in `index.html`:

- Name
- Email
- Phone number
- GitHub URL
- LinkedIn URL
- LeetCode URL
- Education details
- Project details
- Skills
