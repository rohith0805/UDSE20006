# Classifieds Application

A web application for buying and selling used products.

## Technologies

- Node.js
- Express.js
- MongoDB
- Mongoose
- EJS
- HTML
- CSS
- JavaScript
- bcryptjs
- Express Session

## Features

- User registration
- User login
- User logout
- Browse products
- Search products
- Filter by category
- View product details
- Sell products
- My listings
- Delete listings
- Seller information

## Installation

Install dependencies:

npm install

## Database

Make sure MongoDB is running.

Example:

mongodb://127.0.0.1:27017/classifiedsDB

## Seed Database

Run:

npm run seed
