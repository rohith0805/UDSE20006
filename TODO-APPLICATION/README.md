# TODO Application

A full-stack TODO management application where users can register, login, and manage their personal tasks.

## Features

- User registration
- User login
- JWT authentication
- Password hashing
- Create TODO
- View TODOs
- Update TODO status
- Delete TODO
- Task priority
- Due dates
- Task filtering
- User-specific tasks

## Technologies

### Frontend

- HTML
- CSS
- JavaScript

### Backend

- Node.js
- Express.js

### Database

- MongoDB
- Mongoose

### Authentication

- JWT
- bcryptjs
